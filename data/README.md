# Data

## Overview

This folder contains the sample data used by the PPE Compliance Check Agent.

## Contents

- `sample/images/` – Sample images used for testing PPE detection.
- `sample/videos/` – Sample video used for evaluation and monitoring.

## Dataset

The project was developed using a custom PPE dataset for training and evaluation. To keep the GitHub repository lightweight, only representative sample files are included.

## Usage

The sample images and video can be used to reproduce the example outputs shown in the project notebook and documentation.
