# AI Usage Log

## Project

**PPE Compliance Check Agent**

## AI Tool Used

**ChatGPT (OpenAI)**

## Purpose of AI Assistance

AI was used as a learning and development assistant throughout the project. Assistance focused on code organization, debugging, documentation, reproducibility, and repository preparation while preserving the student's understanding and implementation of the project.

## AI-Assisted Tasks

### 1. Notebook Organization

AI assistance was used to:

- Improve Markdown formatting
- Add and refine section introductions
- Improve transitions between project phases
- Enhance explanations for evaluation and monitoring sections
- Organize the final agent workflow

### 2. Code Debugging

AI assisted with troubleshooting issues including:

- Undefined variables
- Google Colab execution order
- Missing Python packages and dependency installation
- Ultralytics and ONNX Runtime setup
- ONNX inference errors
- File and model path errors
- Sample image path errors
- Video generation
- H.264 video conversion
- Output organization
- Final agent initialization and execution issues

AI suggestions were tested in the notebook before being retained in the final implementation.

### 3. Documentation

AI assisted with reviewing and improving project documentation, including:

- `README.md`
- `models/README.md`
- `docs/architecture.md`
- `docs/AI_usage_log.md`

### 4. Repository Organization

AI provided guidance for:

- GitHub folder structure
- Organizing sample data and generated outputs
- Naming conventions
- Repository documentation
- Model-file documentation
- Separating large trained model weights from the GitHub repository
- Using repository-based paths for the final agent

### 5. Reproducibility and Final Verification

AI assisted with the reproducibility review of the final project, including:

- Reviewing project dependencies
- Pinning required package versions in `requirements.txt`
- Testing installation in a fresh Google Colab environment
- Downloading and loading the pretrained `best.pt` model
- Verifying repository sample inputs
- Troubleshooting missing files and incorrect paths
- Testing the final PPE Compliance Agent from a fresh repository clone
- Verifying generation of annotated evidence, JSON reports, and execution traces
- Cleaning temporary debugging code from the final notebook after verification
- Creating and testing the single-command `run_agent.py` execution workflow
- Verifying the final agent processes five sample images and one sample video from a fresh clone

## Student Contribution

The overall project design, dataset preparation, model training, notebook execution, testing, evaluation, debugging decisions, and final verification were completed by the student.

AI assistance was primarily used as a learning resource to explain concepts, troubleshoot errors, improve documentation, and organize the GitHub repository. AI-generated suggestions were reviewed, tested, and modified when necessary before being incorporated into the final project.
